# ✅ UC-01 : Définir l'Objectif Patrimonial

**Statut** : 🚧 En développement  
**Branche** : `feature/uc-01-objectif-patrimonial`  
**Date de début** : 24 novembre 2025

---

## 📋 Description

Permet à l'utilisateur de définir son objectif patrimonial ("Road to 1M") en saisissant :
- Un **montant cible** (ex: 1 000 000 €)
- Une **date cible** (ex: 01/01/2035)

Ces données sont stockées dans la base de données locale (SQLite via Prisma) et constituent la base de tous les calculs futurs.

## 🔌 API Electron

### `goal:save`
Sauvegarde un nouvel objectif patrimonial.

**Paramètres** :
```typescript
{
  targetAmount: number,  // Montant cible (ex: 1000000)
  targetDate: Date       // Date cible
}
```

**Retour** :
```typescript
{
  success: boolean,
  goal?: Goal,
  error?: string
}
```

### `goal:get`
Récupère l'objectif actuel.

**Retour** :
```typescript
{
  success: boolean,
  goal?: Goal | null,
  error?: string
}
```

## 📊 Modèle de Données

```prisma
model Goal {
  id          Int      @id @default(autoincrement())
  targetAmount Float   // Montant cible
  targetDate  DateTime // Date cible
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

**Règle métier** : Un seul objectif actif à la fois (le plus récent).

## 🧪 Tests Manuels

### Scénario 1 : Première Utilisation
1. Lancer l'application
2. Le formulaire s'affiche (pas d'objectif existant)
3. Saisir montant : `1000000`
4. Saisir date : `2035-01-01`
5. Cliquer sur **Enregistrer**
6. ✅ Message de succès
7. ✅ Écran de confirmation s'affiche

### Scénario 2 : Chargement d'un Objectif Existant
1. Relancer l'application
2. ✅ L'objectif précédent est chargé automatiquement
3. ✅ L'écran de confirmation s'affiche

### Scénario 3 : Modification de l'Objectif
1. Cliquer sur **Modifier**
2. Le formulaire réapparaît avec les valeurs actuelles
3. Modifier les valeurs
4. Sauvegarder
5. ✅ Nouvel objectif enregistré

1. Saisir un montant négatif → ❌ Erreur
2. Saisir une date passée → ❌ Erreur
3. Laisser un champ vide → ❌ Erreur
