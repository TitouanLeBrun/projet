# UC-03 : Saisir les Snapshots (Points de Valeur)

## 📋 Vue d'ensemble
Cette fonctionnalité permet à l'utilisateur de saisir périodiquement (généralement mensuellement) la valeur actuelle de chaque actif. Ces "snapshots" constituent l'historique de valorisation du patrimoine.

## 🎯 Objectifs
- Permettre la saisie rapide des valeurs actuelles de tous les actifs
- Enregistrer un snapshot daté pour chaque actif
- Afficher l'historique des snapshots par actif
- Calculer automatiquement la valeur totale du patrimoine
- Préparer les données pour le graphique "Road to 1M"

## 📊 Schéma de Données

### Table `Snapshot` (déjà existante)
```prisma
model Snapshot {
  id          Int      @id @default(autoincrement())
  assetId     Int
  value       Float    // Valeur de l'actif à cette date
  date        DateTime @default(now())
  createdAt   DateTime @default(now())
  asset       Asset    @relation(fields: [assetId], references: [id], onDelete: Cascade)

  @@index([assetId, date])
}
```

## 🔄 Flux Utilisateur

### Saisir un Snapshot
1. L'utilisateur clique sur l'onglet "📸 Saisie" ou "💰 Valorisation"
2. Le système affiche la liste de tous les actifs actifs
3. Pour chaque actif, un champ de saisie est disponible
4. L'utilisateur entre la valeur actuelle de chaque actif
5. L'utilisateur clique sur "💾 Enregistrer les Valeurs"
6. Le système :
   - Crée un snapshot pour chaque actif avec la date du jour
   - Calcule la valeur totale du patrimoine
   - Affiche un résumé

### Consulter l'Historique
1. L'utilisateur clique sur un actif
2. Un panneau s'affiche avec :
   - Graphique d'évolution de la valeur
   - Tableau des snapshots précédents
   - Statistiques (min, max, moyenne, tendance)

## 🎨 Interface Utilisateur

### Composants
- **`SnapshotForm.tsx`** : Formulaire de saisie des valeurs
- **`SnapshotHistory.tsx`** : Historique par actif
- **`SnapshotSummary.tsx`** : Résumé du patrimoine total
- **`SnapshotsPage.tsx`** : Page principale de saisie

### Design
- **Formulaire de saisie** : Liste compacte avec input par actif
- **Indicateur visuel** : Dernière valeur connue affichée
- **Validation** : Valeur > 0 requise
- **Total en temps réel** : Calcul automatique pendant la saisie
- **Badge "Nouveau"** : Sur les actifs jamais valorisés

## 📝 Règles Métier

### Fréquence de Saisie
- **Recommandée** : Mensuelle (ex: le 1er de chaque mois)
- **Minimum** : Au moins une fois pour déclencher les calculs
- **Pas de contrainte** : L'utilisateur peut saisir quand il veut

### Valeurs
- Toujours > 0
- Stockées en Float (ex: 12345.67)
- Devise implicite : EUR (€)

### Date
- Par défaut : Date du jour
- Possibilité future : Saisie rétroactive avec date personnalisée
