# UC-02 : Créer/Gérer les Actifs (Patrimoine Actuel)

## 📋 Vue d'ensemble
Cette fonctionnalité permet à l'utilisateur de gérer son inventaire d'actifs patrimoniaux. Chaque actif représente une ligne d'investissement (Crypto, Bourse, Immobilier, Cash, etc.) avec un ROI espéré.

## 🎯 Objectifs
- Permettre la création, modification et suppression d'actifs
- Catégoriser les actifs par type
- Définir un ROI espéré pour chaque actif
- Afficher la liste des actifs avec leurs informations

## 📊 Schéma de Données

### Table `Asset`
```prisma
model Asset {
  id          String        @id @default(uuid())
  name        String        // Ex: "Bitcoin", "PEA ETF World"
  category    AssetCategory // Enum: CRYPTO, STOCK, REAL_ESTATE, CASH, OTHER
  expectedRoi Float         // ROI annuel espéré en % (ex: 8.5 pour 8.5%)
  isActive    Boolean       @default(true)
  createdAt   DateTime      @default(now())
  updatedAt   DateTime      @updatedAt
  
  values      AssetValue[]  // Relation avec l'historique des valeurs
}

enum AssetCategory {
  CRYPTO
  STOCK
  REAL_ESTATE
  CASH
  OTHER
}
```

## 🔄 Flux Utilisateur

### Créer un Actif
1. L'utilisateur clique sur "➕ Ajouter un Actif"
2. Un formulaire s'affiche avec :
   - **Nom** : Champ texte (ex: "Bitcoin", "Livret A")
   - **Catégorie** : Sélecteur (Crypto, Bourse, Immobilier, Cash, Autre)
   - **ROI Espéré** : Champ numérique avec % (ex: 8.5%)
3. L'utilisateur valide
4. Le système enregistre l'actif
5. L'actif apparaît dans la liste

### Modifier un Actif
1. L'utilisateur clique sur "✏️ Modifier" sur un actif
2. Le formulaire se pré-remplit avec les données actuelles
3. L'utilisateur modifie les champs
4. L'utilisateur valide
5. Le système met à jour l'actif

### Supprimer un Actif
1. L'utilisateur clique sur "🗑️ Supprimer" sur un actif
2. Une confirmation s'affiche
3. L'utilisateur confirme
4. Le système marque l'actif comme inactif (`isActive = false`)
5. L'actif disparaît de la liste principale

## 🎨 Interface Utilisateur

### Composants
- **`AssetForm.tsx`** : Formulaire de création/modification
- **`AssetList.tsx`** : Liste des actifs avec actions
- **`AssetCard.tsx`** : Carte individuelle pour chaque actif

### Design
- Liste sous forme de cartes
- Couleurs par catégorie :
  - 🟡 Crypto : Jaune/Or
  - 📈 Bourse : Bleu
  - 🏠 Immobilier : Vert
  - 💵 Cash : Gris
  - 🔷 Autre : Violet
- Badge avec le ROI espéré
- Actions : Modifier / Supprimer
